- Building the logics to find movies from a database per director, year, average of the year, etc...

## 💻 Stack:
- HTML
- CSS
- Javascript
- Jest

## 📋 Requirements
- Google Chrome (v.91+)
- Github

## 📦 Dependencies

Before running the project, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (Latest LTS recommended)
- [npm](https://www.npmjs.com/) (comes with Node.js)
- [Jest](https://jestjs.io/) for testing

### 📥 Install dependencies

1. **Clone the repo**  
   ```
   git clone https://github.com/OhMyLaia/sprint2.2-E-commerce-remote.git
   cd sprint2.2-E-commerce-remote
2. 	To run tests with Jest:
 	```
    npm test
3. 	Ensure package.json includes the necessary scripts and dependencies:
   ```
    ("test": "jest")
   	("devDependencies": "jest".....)
  ```
